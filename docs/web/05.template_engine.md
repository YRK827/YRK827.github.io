# 1. Truthy and Falsy in JavaScript

In JavaScript, most values evaluate to **true**, except a small group of specific values that evaluate to **false**.

## ✔ Truthy Values
Values that become `true` when evaluated in a boolean context:
- 1, 2, -1, 3.14  
- "hello" (any non-empty string)  
- [] (empty array)  
- {} (empty object)  
- function() {}  

## ✔ Falsy Values
These always evaluate to `false`:
- 0  
- "" (empty string)  
- null  
- undefined  
- NaN  
- false  

Boolean evaluation is important when using `if`, loops, logical operators, etc.

# 2. Query String

A **query string** is the `key=value` information added after `?` in a URL.  
It is used to send small pieces of data to the server.

### ✔ Example
localhost:8080?id=yrk&pw=1234

Here:
- id = yrk  
- pw = 1234  

This information is sent to the server.

### ✔ How to read query strings in Express
```js
app.get('/login', (req, res) => {
  console.log(req.query.id);  // 'yrk'
  console.log(req.query.pw);  // '1234'
});

### 3. ASCII Code & UTF-8 (Character Encoding)

#### ✔ ASCII
- Supports only English letters, numbers, and symbols  
- Uses 1 byte (0–127)  
- Cannot represent Korean  

#### ✔ UTF-8
- Standard encoding of the web  
- Supports all languages  
- English characters = 1 byte  
- Korean characters = 3 bytes  
- HTML files are usually saved in UTF-8  

Character encoding matters so that text appears correctly across systems.

### 4. Static Page vs Dynamic Page

#### ✔ Static Page
- Delivered to the user exactly as written  
- The content never changes  
- Examples: company info pages, announcements, basic introductions  

#### ✔ Dynamic Page
- The HTML output changes depending on variable data  
- The server generates HTML on the fly  
- Does not rely on a single fixed HTML file  
- Works like creating a virtual rendered layer instead of a pre-made file  

**Example**
- If A logs in → “Hello, A!”  
- If B logs in → “Hello, B!”  

Any page whose content changes based on input or state is dynamic.

---

### 5. Template Engine

#### ✔ What is a Template Engine?
A template engine:
- Creates an HTML template  
- Inserts variables into it  
- Generates a final HTML page dynamically  

**Formula:**  
`HTML template + Server data → Rendered HTML`

#### ✔ Why do we need it?
Plain HTML cannot contain variables like:  
```html
<h1>Hello, OOO</h1>
```
Template engines allow:=
<h1>Hello, <%= name %></h1>

This enables dynamic content inside HTML.

⸻

## 6. Express + Template Engine (EJS / Eta) Workflow

Frameworks like **Express** usually generate dynamic pages using templates.

### ✔ Rendering Workflow
1. The user visits a URL  
2. The server gathers data (database, query string, etc.)  
3. The server inserts that data into a template file (.ejs, .eta, etc.)  
4. The final HTML is rendered and sent to the browser  

---

### Example Template (EJS / Eta)

```html
<h1>Welcome, <%= username %></h1>
```

## Example Server Code
app.get('/', (req, res) => {
  res.render('home', { username: "Yerin" });
});
