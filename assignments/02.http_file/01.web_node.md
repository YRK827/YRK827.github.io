## 2. Ajax / Long Polling / Hybrid App
- **Long Polling**: send a request in advance and wait until the respond comes.  
  - Feels like: you reached out and now just waiting for the reply.  
- **Ajax**:  
  - Lets the server update content **without reloading the whole page**.  
  - Normal way: Request → Respond → Render  
  - Ajax: only updates parts of the page instead of re-rendering everything  
- **Hybrid Application**:  
  - Uses methods like Ajax to fix the annoying thing where “no request → no respond”.  
  - Still need to study the exact definition more.



## 3. Network Basics
- **UDP (User Datagram Protocol)**  
  - Similar to TCP, but no need for a connection (TCP handshake)  
  - Sends data **all at once** (like uploading)  
  - Good for: streaming or sending lots of data quickly without loss  
  - Bad: if data is lost, there’s no automatic way to recover  
- **Compared to TCP**  
  - TCP: connects first, safe delivery, can resend if lost  
  - UDP: sends fast without connecting, but less reliable

## 1. Basic Terminal Commands
- **cd <path>**: Move to a specific directory
  - If the path has spaces, an error happens
  - Solution 1: Add `\` before the space
  - Solution 2: Wrap the whole path in `" "`
- **pwd**: Show the full path of the current directory
- **node --version / npm --version / nvm --version**: Check installed Node.js, npm, and NVM versions


## 2. Initialize a Node.js Project
- **npm init**: Initialize a Node.js package → creates a `package.json` file
- Example input fields:
  - **package name**: (00.http) → can use the default; this is the name used for the package on the website
  - **entry point**: the main file of the project (e.g., `index.mjs`)
- After initializing in the terminal, you can check the `package.json` file in Visual Studio
  - If you need to change the package later, you can edit this file directly


## 3. Terminal Commands to View Files/Folders
- **ls**: Show files/folders
- **ls -a**: Show all files (including hidden files)
- **ls -al**: Show detailed information
- **ls -alh / ls -lh**: Show sizes in human-readable units
